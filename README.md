# Text Recognition and Detection using EasyOCR and OpenCV

This project demonstrates how to perform Optical Character Recognition (OCR) on images using Python. It uses **EasyOCR** to detect and recognize text within an image, and **OpenCV** to visually highlight detected text regions with bounding boxes and text overlays.

---

## Features

- **Text Detection & Recognition**: Extracts text and confidence scores using EasyOCR.
- **Bounding Box Visualization**: Draws green polygon outlines around detected text regions.
- **Text Overlay**: Labels detected text directly onto the image in red above each detected region.
- **Interactive Output**: Displays the final processed image using OpenCV.
